# 题目与答案证据审计

本参考用于把答题材料可靠地接入全文精读。它产出的是可复查的答案记录和复盘依据，不是对学习者语法能力的自动诊断。

## 1. 先确认文件中有什么

- 分别登记原文、题目、用户提交答案、判题界面、标准答案或解析的来源。一个 PDF 可能同时包含其中多项，不能因为文件名叫“答案”就确定其角色。
- 区分题号、题干、作答位置、用户选择、正确答案提示和解析文字；确认文章与题目属于同一套材料。
- 对扫描件、截图型 PDF 和带判题颜色的页面，必须实际查看页面图像。文本提取适合搜索与比对，不能替代视觉辨认选中状态、颜色、删除线和标注位置。
- 保留原有题号与段落字母。OCR 不清楚的字词、分页接缝和被遮挡区域单独标记，不靠“看起来像”补成确定事实。
- 读取本组题的实际作答要求：填空检查字数或数字限制、是否必须从原文取词、单复数与拼写；匹配或选择检查是否允许重复选项及所需答案数量。按题面执行，不能从别套题默认沿用。

## 2. 颜色和界面状态按材料确认

先看图例、勾叉、得分提示、标签与选择框，再判断颜色的含义。不能固定采用“绿色是用户答案”“红色就是错误”之类规则。

- 同一颜色可能表示正确答案、当前选中项、搜索高亮或阅读批注；颜色相同不意味着证据角色相同。
- 用户明确说明的颜色约定只适用于相应材料。换网站、页面或导出方式后重新确认。
- 看到绿色正确答案，不等于看到用户当时提交的答案；用户答案未保存或未展示时，记录“未知”。
- 只有颜色而没有足够上下文时，先保存“绿色显示为 X”等观察，再将其解释标为待确认。
- 用户已说明原文高亮没有诊断意义时，忽略它对选句和错因判断的影响。

## 3. 建立可追溯的答案记录

每题至少区分以下字段；实际交付可用紧凑表格，缺失值不能伪造。

| 字段 | 内容 |
| --- | --- |
| 题号与题型 | 原始题号、对应任务，如段落信息匹配 |
| 用户答案 | 提交值、来源页码或截图位置；未知则明确未知 |
| 标准答案 | 答案值及来源；与用户答案独立记录 |
| 判定 | 正确、错误或暂不能核实 |
| 原文锚点 | 段落、句子编号或独特起始短语，必要时附来源页码 |
| 判题依据 | 原文如何满足题干主体、关系与限定；是否符合本题作答格式 |
| 待确认项 | 模糊字符、界面含义、答案来源冲突等 |

- 优先使用用户提供且能对应本题的可靠答案页；若来源之间冲突，先核对版本、题号与题干，不静默选择一个结果。
- 没有标准答案时，可依据原文提出“推定答案”并说明证据；不得称其为官方答案。
- 整套试卷的成绩和用时不能直接当成本篇文章的成绩和用时。
- 统计正确数前，确认用户答案确实可见、题目范围一致；无法核实的题目不能默认正确。

## 4. 逐道错题解释什么

复盘先呈现“题干要求 → 原文证据 → 为什么对应”，再核对用户所选项的符合与不符合之处。使用具体词语与关系，不只说“定位错误”。

1. **题干目标**：找的是变化、原因、例子、对比、结果还是态度？把主体、动作或关系、时间、程度、范围及否定一起核对，不能只看主题词。
2. **正确证据**：给足够短的原文锚点，说明同义改写、范围或因果如何满足完整题意；填空等题还须核对作答限制。理解正确但格式不符与理解关系出错应分开记录。
3. **所选项的吸引点**：指出它确实含有什么相关话题、词语或结构，不能把相近选项说成毫无关系。
4. **未满足之处**：有明确差异才指出，例如只介绍措施而未说明撤销，或只有现状而无过去与现在的对比。若选项语义确有重叠，复核题型、范围及上下文；仍不能区分时保留不确定性，不为贴合答案强编排除理由。
5. **必要的精读补充**：若正确证据跨两句或跨段落，补足连接；若误读可能来自一个结构，把该结构纳入全文精读覆盖。

解释相近选项时只比较与判定有关的差异，不能推广成“越概括越好”。段落信息匹配查找所述信息，标题匹配才核对段落整体重点；某段包含多个信息点不等于题面一定允许重复使用，应另查作答要求。

## 5. 将观察与错因假设分开

“用户选了 D，标准答案为 C”是可核实的观察；“用户不认识 whereas”需要额外证据，不能由选错直接推出。

- 可写：“若把前半句读成时间背景，就容易漏掉此处的过去／现在对比；本题需要检查这个连接。”
- 不可写：“你选错说明你不会让步从句。”除非用户明确解释了自己当时的理解，而且证据确实支持这一判断。
- 一道题可能同时涉及词义、句内关系、段落定位和选项比较。没有用户回忆或过程记录时，给一两个可检验的可能卡点，不编造唯一原因。
- 用短问题检验可能卡点，每个回答对应一个可定位关系，避免一个 yes/no 同时检验两种理解。接受等义表达，不能仅因没有使用术语就判为不会。
- 保留用户原始回答与提示情况，按 [反馈记录标准](reading-method.md#6-复核与反馈迭代) 区分独立读对、提示后理解、仍误读与未知；记录支持判定的依据，再调整讲解。
- 正确答案也可能来自排除、猜测或回看。做对一道题不能证明整句所有关系都已熟练，更不能据此删除有学习价值的全文候选句。

## 6. 与全文精读合并前检查

- 全文选句依据是否独立于错题存在？错题相关的重要证据是否得到覆盖？二者都应保留。
- 每一条“用户答案”和“正确答案”能否回到原始材料核对？界面显示与推断是否有明确区分？
- 是否完整核对主体、关系、限定及本题作答约束？选项确有重叠时，是否保留证据不足而未强编差异？
- 是否将不确定错因写成了确定诊断，或把看不见的提交答案误记为正确？
- 最终文稿可先放全文精读，再放错题复盘、词汇与练习答案；遵从用户已确认的顺序，不让错题部分挤掉其他经典长难句。
