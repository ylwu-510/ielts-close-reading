# 阅读精读内容标准

本参考规定如何从一篇文章制作适合学习者的精读材料。先建立全文难点候选，再用答题证据调整；最终产物应能让学习者看清具体连接、完成迁移练习，并核对自己的理解。

## 1. 确定读者水平与材料边界

- 记录已知的词汇量估计、近期正确数、用时、考试形式，以及用户明确说过的卡点；未知项保持未知，不因缺少一项信息停止可做的工作。
- 自测词汇量只能帮助预估词汇负担，不能证明某个词已掌握；正确数和超时也不能直接证明某项语法薄弱。
- 优先采用用户指出的困难，例如“修饰信息接不上”“找到了主谓却仍不懂作者要说什么”。不要把普通主谓、常见 but 或 whether 一律当成需要重新教授的内容。
- 明确本次处理的是全文精读、指定句子还是错题复盘。未被要求时，不添加限时训练计划、逐段起标题任务或泛泛学习建议。

## 2. 先看全文，再用答题证据校准

第一遍在不依赖错题的情况下通读全文，列出值得讲的候选；随后依据 [答案审计](answer-audit.md) 调整覆盖。不要先规定必须选多少句。

| 候选层级 | 选择依据 | 处理方式 |
| --- | --- | --- |
| 词义负担 | 不常见词义、熟词生义、固定搭配 | 放入简短词汇表，解释本文义 |
| 短提示 brief | 一处省略、修饰或范围是主要障碍，其余关系直接 | 点明这一处连接，不硬凑完整结构拆解 |
| 详解 full | 插入介绍、嵌套修饰、远距离并列、否定范围等叠加影响理解 | 给结构示意、关键连接和即时同构练习 |

- 每个候选写出具体入选理由，例如“人物介绍隔开主语和主句谓语”，不能只写“句子长”。
- 阅读难点不只存在于句子主干：修饰部分可能承载设计依据、限制条件、作者批评或题目定位信息。
- 做对相关题目不能成为删除经典长难句的理由；错题则应检查是否遗漏必要的原句、词义或段落连接。
- 初次深浅由句子的难点组合决定，不凭词汇量估计假定某项结构已掌握。后续减少该难点的讲解须有理解反馈支持；重复结构则突出各句新增的关系。
- 原文高亮的用途未获确认时，不把高亮当作用户不会的证据。

## 3. 每个入选句子的内容

按原文顺序组织，用段落字母与句号序号定位，例如 A2。标题写本句具体难点，不要求学习者在考试中另写标题。

full 使用下列完整结构；brief 保留原句、译文与单点连接，可省去结构示意和重复解释，练习按需要保留。用户已要求每句配练习时，两种深度都须配练习。两者是讲解深度，不是预先分配的数量名额。

1. **完整原句**：逐字保留词语和标点，英文作为一个连续段落自然换行。不把英文意群和中文交替排放，不为显示结构改写原句，不给原句内部片段加粗。只有用户明确偏好时才使用句内斜杠。
2. **整句译文**：自然且完整，保留否定、程度、可能性、条件、并列关系和施事；不把上下文推论偷偷写成原句明说的内容。
3. **结构示意**：用一至两行显示本句的骨干或逻辑。明确这是压缩示意，可以省略修饰语，不能伪称为完整原句或完整句意。
4. **关键连接**：只选真正影响理解的关系，每处写“原文定位短语 → 连接关系 → 简短依据或含义”，不为凑条数拆碎原句。
5. **同结构练习**：紧接本句解析，使用原创例句和具体问题；参考答案统一放在文末，便于先尝试再核对。

## 4. 让连接关系可见

“补充说明”“注意理解”“先抓主干”不足以构成解析。必须说清修饰哪个词、占什么位置、与哪一项并列，或某个条件与否定覆盖到哪里。

可采用以下具体写法，例句均为自编：

- `the books students borrow`：`students borrow → 修饰 books`；可补成 `books that students borrow`，books 是 borrow 的对象，因此这里可以省略关系词。
- `the plans developed by the team`：`developed by… → 修饰 plans`；plans 是被制定的对象，developed 在这里不是全句另一个过去时谓语。还原关系从句时须按上下文选择时态，不能一律补成 is。
- `by testing ideas and collecting feedback`：`testing / collecting → 同受 by 支配`；这是两种并列做法，不要把第二项接成独立结果。
- `however useful it might be`：`however + 形容词 → 无论多么`；同时保留 might 的可能性，不能译成“然而它很有用”。
- `would be impossible using only numbers`：`using only numbers → 限定不可能的条件`；意思是仅靠数字办不到，不能扩大成无论采用何种办法都办不到。

检查每句时，按实际需要覆盖：

- **修饰与省略**：说明被修饰词；若还原省略形式能消除误读，就展示简短还原。
- **否定与限制**：标明 not、only、solely、without 等具体影响的范围，保留 not…but… 和 not only 等整体关系。
- **并列**：指出 and/or 两侧连接的是动作、名词、从句还是被忽略的事项；否定语境中的 or 不一定表示实际二选一。
- **指代**：给出 it、they、their 等在本句或上下文中的具体对象；依据不足时保留歧义，不凭最近名词机械判定。
- **情态与假设**：区分“可能”与“必然”，过去反事实与真实过去，目的与已经发生的结果。
- **句间连接**：关键处检查例子支持哪项观点、承接词接回什么、结论收回哪条论述。需要时就在该句旁补一句，不扩成逐段起标题任务。

核心示意、关键连接和特别提醒不能重复同一内容。若关键点已经讲清，就不另加一条“注意”。

## 5. 原创同结构练习

- 保留紧接解析的原创同构练习。换话题、降低无关词汇负担，练习目标须对应本句真实难点，不能仅模仿外形或机械替换名词。
- 检查是否能只靠单复数、明显不合理的选项或常识绕过目标关系作答。必要时调整候选对象或问法，使答案能显示连接理解；不能把这种旁路线索命中当成目标已掌握。
- 一个诊断回答对应一处可定位关系，例如“否定受哪个条件限制？”。检查多项关系时分别作答，避免把两个判断捆绑成一个 yes/no；不只要求全文翻译。
- 对仍不稳定的关系或反复出现的错误模式，可补少量不预告结构名称的开放短答或换材料判断。数量随反馈决定，不另设练习配额。
- 参考答案统一放在文末，回答具体关系并附自然中文理解；明确例句为自编。接受保留主体、方向、范围等关键含义的等义回答，不要求用户说出语法术语。
- 单独阅读例句时指代应足够清楚；若必须借助后文才能判断，要提供相应上下文，不能在答案里强行消歧。

## 6. 复核与反馈迭代

- 将原句与可靠来源逐句核对；结构示意不能混进原文，译文不能漏掉后半句或修饰信息。
- 检查练习是否真的复现目标结构，问题能否仅凭所给内容回答，答案是否夸大语义。
- 按实际反馈区分“独立读对”（对该条新材料尚未看解析或提示）、“提示后理解”“仍误读”；没有回答则是“未知”。紧跟解析的即时同构题答对，不能自动记为独立读对。
- 在工作记录保存原始回答、对应原文或练习锚点、所给提示与判定依据，并记录练习目标、可接受理解和下一步。正文不必塞入跟踪表；依据记录决定简化、保留或补充练习。
- 用户说“解析不直观”时，重写连接关系和句法依据；不能只给旧长段落换标签。
- 用户说“太密、太长”时，先删重复解析和冗长导读、调整连续排版；不要擅自删除已确认保留的经典句或缩小字体。
- 用户只要求字体、颜色等美化时，锁定全部内容，仅改样式，并核对文本一致性。最终仍需逐页查看实际渲染结果。
